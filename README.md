# Automated Report Generation & KPI Monitoring System

## Overview
This project automates the cleaning, transformation, and analysis of operational data to generate KPI-based reports. It includes rule-based alerts and scheduled execution for consistent reporting.

## Features
- Automated data cleaning and transformation
- KPI calculation with threshold-based alerts
- Weekly report generation
- Windows Task Scheduler integration

## Tech Stack
- Python
- Pandas
- Windows Task Scheduler
